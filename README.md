# Coffee Rush

## What is a Vertical Slice?

A vertical slice is not a short game: it's a slice of a larger game, cut from top to bottom. It cuts through every layer — design, code, art, interface — in a narrow section. That's why the rule is depth before breadth.

The question your delivery answers is: *"if the rest of the game looked and felt like this, would it be worth building?"* Anything that doesn't help answer yes is excess.

## Game Context

In an alternate universe, a mosquito transmits a workplace-exploitation virus through its bite. The unfortunate victim is Fernanda, a waitress who now has to run the coffee shop entirely on her own, while her boss — afflicted by the same symptom — leaves for Las Vegas to gamble away Fernanda's insurance money.
